Backup, restore & instructions

Records are saved online in Supabase; photos are in a private Storage bucket. Browser clearing does not delete cloud records. Sign in with the same account to retrieve them. Internet is required to load and save changes. Each photo is compressed to at most 5,000 bytes before upload; this reduces image clarity.

Download a full JSON backup periodically. To migrate the old local tool, download its backup before clearing browser data, then restore it here. Restoring replaces the current account's inventory after confirmation.

Add a separate record for each size, colour, or purchase-price batch. Edit quantity to correct stock or replenish at the same cost. For different purchase costs, add a new batch.
